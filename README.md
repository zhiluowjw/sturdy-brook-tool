# sturdy-brook-tool

Mobile developer · Kotlin and Jetpack Compose · building tiny tools

学习用的示例项目

## 用法

```bash
cat data.txt | cargo run
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/sturdy-brook-tool.git
cd sturdy-brook-tool
cargo build --release
```
